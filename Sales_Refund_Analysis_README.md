# 📊 Sales and Refund Analysis (Tableau)

An interactive dashboard that identifies refund trends and sales insights using the Global Superstore dataset.

## 📌 Problem Statement
Analyze global sales and refunds to detect high refund regions and improve business operations.

## 🛠️ Tools & Technologies
- Tableau Public
- Excel
- Global Superstore 2016 dataset

## 📈 Features
- Top 10 countries by refund volume
- Category-wise refund patterns
- Sales vs refunds comparison
